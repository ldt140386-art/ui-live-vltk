# Documentation Archiving

When completing a work session, archive all .md artifacts to the project's Docs folder:
`E:\Jx1\Source_unpak UI_Live_VLMP\Docs`

## Files to Archive
- Implementation plans → prefix with `Implementation_Plan_`
- Learning proposals → prefix with `Learning_Proposal_`
- Task checklists → prefix with `Task_Checklist_`
- Walkthroughs → prefix with `Walkthrough_`
- Rules → prefix with `Rule_`

## Naming Convention
- Use PascalCase with underscores: `Walkthrough_CrossPAK_UI_Composite.md`
- Name should describe the content topic, not generic labels
- Use Vietnamese or English depending on content language

## When to Archive
- At the end of major feature implementations
- When user explicitly requests `/learn` or save
- Before ending a long conversation session
